# Post-action social sharing: platforms, mechanics, poster and priority
Researched: 2026-11-08 · Informs: [social-sharing](../prd/archive/2026-11-social-sharing.md)

Every URL below was observed on 2026-11-08 unless a different date is given. "not verified" marks a claim no fetched source confirmed.

## Summary
- Platform priority for a US anti-war civic tool: **1. Instagram Story** (51% of US adults, 79% of 18–29; the top news source for 18–29 at 43%; Democrats 29% vs Republicans 20%) → **2. the OS share sheet as a whole** (Messages/iMessage, WhatsApp, Signal, Telegram, Instagram DM — one `navigator.share` call, zero per-platform work, private-first which matches the funnel) → **3. Facebook** (70% of adults, 78% of 30–49, 40% of adults get news there) → **4. X / Threads / Bluesky** text intents (S effort each; X is 25% of adults but 57% of its users get news there) → **5. TikTok, Snapchat, LinkedIn, Reddit** deferred (no usable web intent or wrong audience).
- No surveyed civic tool (5 Calls, Resistbot, Change.org, Mobilize, Action Network, EveryAction, Engaging Networks, Na Pressão) renders an image per user action; all share a link plus canned text, and 5 Calls shows a per-issue server image. A per-action poster is a differentiator, not table stakes.
- Instagram has no web URL scheme for Story or feed. The only path from a web page is `navigator.share({files:[png]})` → OS sheet → user taps Instagram → Story/Feed/Message. Supported on iOS Safari 14+ and Chrome Android 76+; not on Firefox or desktop Linux Chrome. Field reports: send the file alone (text+url makes iOS targets take the link and drops "Save Image"), build the PNG before the tap (user activation expires), and expect quirks (a 2023 report that Instagram opened only Reels unless `title:''`; an open WebKit bug where Story sharing blanked Safari on iOS 17.3 beta).
- Poster generation: **on-device Canvas 2D**, one 1080×1920 master drawn from goal text + shapes + one embedded font, encoded with `canvas.toBlob('image/png')`, nothing user-identifying in it. Server-side rendering is out: Workers Free gives 10 ms CPU per request and Satori/resvg pipelines are reported at ~90 ms warm. Keep the existing build-time 1200×630 OG card for link previews (Facebook, X, Threads, WhatsApp, Telegram, iMessage all pull it from the shared URL). Fallback where files cannot be shared: "Download poster" + "Copy caption" + `instagram://` or instagram.com link.
- Evidence that sharing a completed action moves others: strong for close-tie social proof (Bond 2012: ~340k extra votes, 4 indirect per 1 direct, close friends only; Jones 2017 replicates at smaller size), moderate for relational asks (vote-tripling RCTs +0.5 to +1.15 pp), and a warning that *public* token support reduces the sharer's own follow-through (Kristofferson 2014) — which is why the poster comes after the call, never before.

## 2. Share mechanics from a mobile web page
### Instagram
- No web URL scheme for Story or feed. Meta's Stories sharing doc covers native iOS/Android only and requires a Facebook App ID since Jan 2023 — [developers.facebook.com sharing-to-stories](https://developers.facebook.com/docs/instagram-platform/sharing-to-stories). Direct iOS feed sharing was removed even for native wrappers; Instagram now shows the OS share dialog — [Median docs](https://docs.median.co/docs/social-share-instagram) (page updated 2026-10-23).
- Web path: `navigator.canShare({files})` then `navigator.share({files:[File]})`; the OS sheet lists Instagram when installed; Instagram then offers Story / Feed / Message. Field reports: (a) combining `files` with `text`/`url` made iOS targets take the link and removed "Save Image"; file-only fixed it; render the PNG *before* the tap because awaiting canvas + fonts expires the user activation — [dev.to shibowen336](https://dev.to/shibowen336/sharing-a-canvas-generated-image-on-ios-with-the-web-share-api-2j0m) (1080×1920 certificate, year not shown); (b) 2023-06-15 report that image files opened only the Reels composer unless `title:''` was passed, after which Story and Message appeared — [zenn.dev/tgfjt](https://zenn.dev/tgfjt/articles/befba855ee4095); (c) WebKit bug 267419 "Sharing photo/video to Instagram story breaks Safari" (black screen after share), reproduced on iOS 17.3 beta, status NEW, last comment 2024-01-11, reporter says it worked on iOS 15/16 — [bugs.webkit.org](https://bugs.webkit.org/show_bug.cgi?id=267419). Behaviour on iOS 18/26 and current Android Instagram: not verified — must be device-tested before the PRD commits to "Story first".
- Links: Story link sticker is available to all accounts since 2021-10-27 (new accounts and policy violators excluded), added manually by the user — [about.instagram.com](https://about.instagram.com/blog/announcements/expanding-sharing-links-in-stories-to-everyone). Feed captions never render clickable links (third-party guides only; official help page not fetched) — [outfy](https://www.outfy.com/blog/?p=19882). So the poster must carry the short URL as text.

Stories vs feed reach (brand accounts, Jan–May 2025, ~160k Stories): feed reach rate 4.0% vs Stories 3.3% at 1–5K followers, 3.7% vs 0.6% at 10–50K; one Story reaches 6.3%, a 13-Story sequence 37.8% — [Socialinsider benchmarks](https://www.socialinsider.io/social-media-benchmarks/instagram-stories-benchmarks). Why Instagram, sheet, Facebook, then X/Threads/Bluesky: Instagram is the only platform that is both majority-used by 18–49 and the top news source for 18–29, and it skews Democratic. The OS sheet captures messaging (WhatsApp 26%, iMessage not surveyed) at no extra effort and keeps the share private, matching the funnel. Facebook still has the broadest reach and the highest news share among 30–49 and older. X, Threads and Bluesky are cheap text intents with a politically engaged minority. TikTok is 65% of 18–29 but has no web share path for an image or a link.

| Surface | Size / ratio | Safe zone | Source |
|---|---|---|---|

| X / Facebook / Threads / WhatsApp / Telegram / iMessage link card | 1200×630 (1.91:1) via `og:image` — the existing OG card | n/a | X card and Meta OG behaviour per §2 docs |
| Bluesky | link card from URL; image attachments only from the app | n/a | §2 |
| Snapchat sticker | 400×400 PNG, transparent, <1 MB | n/a | [developers.snap.com](https://developers.snap.com/snap-kit/creative-kit/web) |
- Master: one 1080×1920 render with all text inside a central 1080×1350 band (y 285–1635) satisfies Story safe zones and crops losslessly to 4:5 for feed; 1.91:1 cannot be cut from it without re-layout, so the OG card stays a second template. Two templates total, one of them already built.
- Legibility: no pixel threshold is documented; guides give 28 pt body / 36 pt headline minimums on a 1080-wide Story at 1 pt = 1 px — [coinis](https://coinis.com/how-to/design-story-post-for-instagram). A 1080 px Story is shown at ~390 CSS px wide on an iPhone, so 36 px ≈ 13 CSS px; use ≥44 px for body, ≥72 px for the headline, ≥40 px for the URL.

## 5. Generating the poster
| Option | Cost | Latency | Privacy | Risks | Verdict |
|---|---|---|---|---|---|
| On-device Canvas 2D → `toBlob('image/png')` → `File` → `navigator.share` | $0 | <100 ms on phone for text+shapes | Nothing leaves the device; poster carries only goal/action copy and the public URL | Must `await document.fonts.load('700 72px Font')` before drawing (Baseline since 2020 — [MDN FontFaceSet.load](https://developer.mozilla.org/en-US/docs/Web/API/FontFaceSet/load)); iOS canvas cap ~16.7M px (2M px here, fine) and `toBlob` can return null — guard it — [pqina](https://pqina.nl/blog/canvas-area-exceeds-the-maximum-limit/); pre-render on receipt mount so the tap handler calls `share()` synchronously | **Recommended** |
| Worker render (Satori/resvg-wasm, Takumi) | Free plan: 10 ms CPU/request, 100k req/day, Error 1102 on overrun — [Cloudflare limits](https://developers.cloudflare.com/workers/platform/limits/) | satori-cf self-reports ~270 ms cold / ~90 ms warm (not Workers-measured); `@cf-wasm/og` README warns of the CPU limit — [README](https://unpkg.com/@cf-wasm/og@0.4.1/README.md); Takumi claims 2–10× Satori, no independent Workers benchmark — [nuxtseo](https://nuxtseo.com/docs/og-image/renderers/takumi) | Poster URL would encode the action, so the request log sees what the user did | Needs Workers Paid ($5/mo, breaks $0) or a cache that only helps repeated goals; a 1080×1920 PNG is ~5× the pixels of the OG card | Reject |
| Build-time static per goal (Astro endpoint, like the OG card) | $0 | 0 at request time | Same as OG card | Cannot reflect the specific ask/office/outcome chosen on the receipt without a combinatorial explosion; fine for the 1200×630 link card | Keep for OG only |
Fallback when `canShare({files})` is false (Firefox, desktop Linux, WebView, old iOS): show the poster inline, "Download poster" (`<a download>`; iOS opens it in a new tab for long-press save — FileSaver note), "Copy caption" (`navigator.clipboard.writeText`), then "Open Instagram" (`https://www.instagram.com/`, which deep-links when the app is installed; `instagram://` scheme not verified from Meta docs). Desktop Chrome on macOS/Windows can share files but has no Instagram target; offer download there too.

## 6. Does post-action sharing drive new actions?
- Bond et al. 2012, *Nature* 489:295, 61M Facebook users, 2010 midterm: social message (friends' faces + "I Voted") vs informational raised validated turnout +0.39 pp; ~60,000 direct votes and ~280,000 via friends (~340,000 total, 0.14% of VAP). All contagion ran through *close* friends (top decile of interaction, ~7% of ties); ordinary friends showed no effect; close friends had ~4× the effect of the message — [PMC3834737](https://pmc.ncbi.nlm.nih.gov/articles/PMC3834737).
- Jones et al. 2017, *PLOS ONE* 12(4):e0173851, 2012 presidential, 15.1M matched users: direct +0.24 pp (95% CI 0.03–0.44); each additional treated close friend +0.10 pp; feed-only treatment no spillover — [journals.plos.org](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0173851).
- Gerber, Green & Larimer 2008, *APSR* 102(1):33, 180k Michigan households: "Neighbors" mailing (your and neighbours' turnout disclosed) +8.1 pp vs Civic Duty +1.8, Hawthorne +2.5, Self +4.9 — social observability of a completed act is the strongest lever measured — [isps.yale.edu](https://isps.yale.edu/node/19738) (effects via [adambrown notes](https://adambrown.info/p/notes/social_pressure_and_voter_turnout)).
- Vote-tripling RCTs (ask a voter to remind three friends): early-voter texts +1.15 pp per housemate (2018), +0.95 pp (FL 2020), on-the-spot pledges +0.51 pp (GA 2022 runoff); run by the practitioner org Vote Rev — [voterev.helpjuice.com](https://voterev.helpjuice.com/en_US/research-and-evidence-faq/questions-about-the-research-and-evidence-behind-vote-rev-and-vote-rev-action-fund-tactics).
- Mobilize bring-a-friend: 14% of signups from invite links (H1 June 2020), +6% total signups after prompt redesign, +20% registrations from social-share clicks; company-reported — [join.mobilize.us](https://join.mobilize.us/blog/continually-helping-supporters-do-more/).
- Kristofferson, White & Peloza 2014, *JCR* 40(6):1149: a *public* token act (like, badge) lowers the actor's subsequent meaningful action; private token support raises it — [typeset.io PDF](https://typeset.io/pdf/the-nature-of-slacktivism-how-the-social-observability-of-an-20ph41c4ix.pdf). Implication: the poster is a receipt of a completed hard action, shown only after the call is logged, never a pledge badge.
- Change.org, Resistbot, 5 Calls publish no share-to-action conversion or K-factor. The only petition datum found is Avaaz: signatures and shares strongly correlated across 366k petitions (correlation, not causation) — [slideshare](https://www.slideshare.net/elaragon/online-petitioning-through-data-exploration-and-what-we-found-there-a-dataset-of-petitions-from-avaaz). Whether a *receipt of a hard action* outperforms a generic invitation has no direct study; the Bond/Gerber results on observed completed acts are the closest evidence.

## 8. Implementation sketch the evidence supports
1. Receipt mounts → `await document.fonts.load('700 72px <Font>')` → draw 1080×1920 canvas (goal headline, action verb, office, date, short URL; no name, no district, no phone) → `canvas.toBlob(cb,'image/png')` → cache `File` + `canShare({files})` result in component state. Nothing here touches the Worker.
2. Primary button "Share poster": `navigator.share({files:[file]})` only, synchronous in the tap handler; catch `AbortError` silently, other errors → fallback (3). Secondary "Share link": `navigator.share({text, url})` — the call that exists today at `web/src/components/ActForm.tsx:169`.
3. Fallback row when `canShare({files})` is false or share throws: poster `<img>` + "Download poster" + "Copy caption" + "Open Instagram"; desktop adds Facebook / X / Threads / Bluesky intent links from §2.
4. Caption text carries the public URL; the OG card (1200×630, build-time) stays the only server-side image.
5. Measure: count taps on each button client-side only (no identifier), compare against receipt renders (no such counter exists yet; not verified that any analytics is wired); the first device-test matrix (§7) is a prerequisite for Story-specific copy.

|---|---|---|---|---|
| Instagram Story + Feed + DM | `navigator.share({files:[poster]})` → OS sheet | no / no (URL drawn on poster; user adds link sticker) / yes (file) | **M** — canvas template, font preload, pre-render on mount, file-only call, device matrix test on iOS and Android Instagram | 1 |
| OS share sheet (Messages, WhatsApp, Signal, Telegram, Mail, Save Image) | same call, or `navigator.share({text,url})` where files unsupported | yes / yes / file where supported | **S** — already shipped for text+url; one branch for files | 2 |
| Facebook | `sharer.php?u=` | no / yes / OG card | **S** — one link; preview from existing OG card | 3 |
| X | `x.com/intent/tweet?text=&url=` | yes / yes / OG card | **S** | 4 |
| Threads | `threads.com/intent/post?text=&url=` | yes / yes / OG card | **S** | 4 |
| Bluesky | `bsky.app/intent/compose?text=` | yes / in text / link card | **S** | 4 |
| WhatsApp (explicit button) | `wa.me/?text=` | yes / in text / preview | **S** — redundant with sheet on mobile; useful on desktop | 5 |
| Telegram | `t.me/share/url` | yes / yes / preview | **S** — low US use (not in Pew table) | 6 |
| Download + copy caption fallback | `<a download>` + clipboard | yes / yes / file | **S** | ships with 1 |
| Snapchat | Creative Kit Web SDK (third-party script) | no / yes / 400×400 sticker | **M** — extra script, sticker asset, 18–29 only | 7 |
| Mastodon | `mastodonshare.com` picker | yes / yes / preview | **S** — small US audience | 8 |
| Reddit | `reddit.com/submit?url=&title=` | title / yes / OG | **S** — wrong format for a personal receipt | 9 |
| LinkedIn | `share-offsite/?url=` | no / yes / OG | **S** — wrong audience | 10 |
| SMS deep link | `sms:?&body=` | yes / in text / rich link | **S** but flaky across devices; sheet covers it | skip |
| TikTok | none from web | — | **L** — would need native app or Share Video API approval | skip |
| Signal | none from web | — | sheet only | skip |
